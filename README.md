# 💰 Gerenciador de Gastos Pessoais

Uma aplicação web **Full-Stack** desenvolvida para ajudar usuários a monitorarem suas finanças de forma simples e direta, permitindo o controle de entradas, saídas e saldos acumulados.

## 🚀 Funcionalidades

- **Dashboard Financeiro:** Visualização clara do Valor Total, Total de Entradas e Total de Despesas.
- **Gerenciamento de Transações:** Modais dinâmicos para adicionar receitas ou despesas informando valor, descrição e categoria.
- **Histórico Cronológico:** Lista de transações ordenada automaticamente da mais recente para a mais antiga, com suporte a exclusão (Delete).
- **Filtro Avançado:** Busca e segmentação de transações por categoria (Alimentação, Transporte, etc.) para análise rápida do fluxo de caixa.

## 🛠️ Tecnologias Utilizadas

### Frontend
- **React** & **TypeScript** (Interface SPA, Hooks e Tipagem estática)
- **JavaScript (ES6+)**
- **HTML5** & **CSS3** (Estilização moderna e modais)

### Backend & Banco de dados
- **Node.js** com **Express** (Construção da API REST)
- **MongoDB** (Persistência e modelagem dos dados de transações)
